# CoA Custom - custom races and more for the Jealous-Sound CoA repack

**Download the latest version: [CoA Custom 1.4](https://github.com/ilusixn/azerothcore-wotlk-coa/releases/latest)**
(retail races, racials for everyone, CoA Bots 1.9.1). The install guide, the patch notes and the credits are on the
release page and in [`apps/coa-custom/README.md`](apps/coa-custom/README.md).

## Prerequisites

1. The **Jealous-Sound CoA repack** (Conquest of Azeroth), started once and working.
2. **CoA Bots 1.9.1** by the **SquidBots team** installed in it:
   [Zyth45/azerothcore-wotlk-coa](https://github.com/Zyth45/azerothcore-wotlk-coa) (branch `coa-bots-1.9.1`),
   [Zyth45/mod-playerbots](https://github.com/Zyth45/mod-playerbots),
   [squidbots-addon](https://github.com/Zyth45/squidbots-addon).
3. The Ascension game client.

## What this branch is

`coa-custom-1.9.1`: our changes on top of CoA Bots 1.9.1's core (`b46a130e`): custom races up to 128, racials for every
race, Esteria's native race appearance, the CoA Custom installer (`apps/coa-custom`). The bot module is
[ilusixn/mod-playerbots `coa-custom-1.9.1`](https://github.com/ilusixn/mod-playerbots/tree/coa-custom-1.9.1).
