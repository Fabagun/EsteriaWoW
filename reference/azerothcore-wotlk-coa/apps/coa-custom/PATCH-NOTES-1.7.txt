=====================================================================
  CoA Custom 1.7 - Grummle, CoA Bots 2.2.1, easier install
  for the Jealous-Sound CoA repack + CoA Bots 2.0 (module 2.2.1)
=====================================================================

NEW
---------------------------------------------------------------------
  - Grummle (race 103, Alliance). Playable on the character screen with its
    own portrait, gnome-size motion, and four racials:
      Pack Toss, Trail Snack, Lucky Foot, Heavy Pack
    Client files: patch-ZZU (create UI), patch-ZZV (voices), patch-ZZW (model).
    One baked look; female uses the male mesh. Armor geosets are limited.
  - CoA Bots 2.2.1 on the shipped worldserver: rated Join as Group with bots,
    rated solo-queue fills, rotation fixes, arena ready pylon, gathering and
    dungeon behaviour from https://github.com/Zyth45/mod-playerbots (branch coa,
    tag v2.2.1). Your accounts and characters are not replaced.

INSTALL / LAUNCH
---------------------------------------------------------------------
  Start without bots:  Start_All_Server.bat
  Start with bots:     CoA-Bots\Start_All_Bots.bat
  Same, from the root: StartAllServer.bat / StartAllServerWithBots.bat
  Wrong name:          Did_You_Mean.bat startallserverwithbots
                       prints  Did you mean this: CoA-Bots\Start_All_Bots.bat

  Extract CoA-Custom-1.7 inside the repack (next to Start_All_Server.bat) and
  run CoA-Custom\Install-Custom.bat. It backs up accounts and characters first.
  Close the game first.

  Linux / Wine: LINUX.md. Manual download is this zip. There is no extra
  client-patch installer for Linux; copy files\client\*.MPQ onto the Windows
  (or Wine) client Data folder. Apply SQL with files\sql\apply.sh.

FIXES
---------------------------------------------------------------------
  - Install no longer dies on creature_template.family (retail families > 127).
    SQL files run in numeric order (1_world.sql before 10_*.sql).
  - Grummle create-screen glue uses the Alliance hall (no PlayGlueAmbience error).
  - Installer typo hints: "Did you mean this: ..." if the folder you pick is not
    the repack or the Ascension client.

KNOWN
---------------------------------------------------------------------
  - Sethrak, Vulpera eyes/head, Realm First, trainer "Show available" are still
    open. Grummle has no dedicated dress-up background.

HOW TO UPDATE
---------------------------------------------------------------------
  Prerequisites: CoA repack main-20261011-a543922b with CoA Bots 2.0 already
  installed (this package ships the 2.2.1 bot worldserver on top of that).
  1. Stop_All_Server.bat, close the game.
  2. Extract this zip into the repack so you have CoA-Custom\.
  3. CoA-Custom\Install-Custom.bat
  4. Play with CoA-Bots\Start_All_Bots.bat (or StartAllServerWithBots.bat).
